# Devcon Archive

Video archive of all Devcon editions @ [archive.devcon.org](https://archive.devcon.org/). Next.js, mostly static; data comes from devcon-api (`/events`, `/sessions`) and local playlists (`src/data/playlists/`).

## Getting started

```bash
pnpm install   # from the repo root
pnpm dev       # http://localhost:3000
```

More context: [docs/notes.md](./docs/notes.md)
