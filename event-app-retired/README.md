# event-app-retired

Static site served on `devcon-event-app.netlify.app` once the Devcon 8 app lives on app.devcon.org (see `docs/app-domain-migration.md`): a worker that switches off installs made from that host, and a "this app has moved" page. Deployed by hand (`netlify deploy --prod --dir event-app-retired`), no build.
